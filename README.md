# Sistema de Voluntariado

## Descripción

Aplicación de consola desarrollada en C# para administrar personas de una organización solidaria.

El sistema permite:

- Registrar voluntarios.
- Registrar coordinadores.
- Mostrar todas las personas registradas y sus actividades.

## Conceptos aplicados

- Herencia
- Encapsulamiento
- Polimorfismo
- Abstracción
- Clases abstractas
- Métodos abstractos
- Modularidad
- Git y GitHub
